### 修掉的真实缺陷
1. **`@ft.control` 子类重声明基类字段会抢占位置参数**：`ui.Button` / `Rating` / `ECharts` / `Pdf` /
   `Video` / `NowPageButton` / `PrevNextPageButton` 等重声明了继承字段（`height` / `value` / `src` …），
   使 `content` 不再位于第一位。改为不重声明 + 在 `init()` 里赋值，或补 `field(kw_only=True)`。
2. **`ChartAxis.label_size` 默认 22 过小**：三位数 y 轴标签被挤进 22px 槽位 → 逐字换行成竖排数字，
   并溢出到相邻文本上（表现为 section 提示首字母出现重影）。新增
   `_data.y_axis_label_size` / `x_axis_label_size`，四个图表显式设置；
   同时 `show_min=False, show_max=False` 避免极值标签与自动刻度重叠。
3. **`_data.parse_data` 不支持分类轴**：`float("1月")` 抛 ValueError。改为分类取值退回下标，
   新增 `resolve_x_labels` 保留原始文本；`x_axis_labels` 支持数值轴 / 分类轴。
4. **`ft.TextButton(url_target=...)` 在 1.0.0 已移除** → `url=ft.Url(..., target=ft.UrlTarget.BLANK)`。
5. **`ft.Audio` 在 1.0.0 是 `ft.Service` 而非 `ft.Control`**：放进控件树会报
   `Unknown control: Audio`。Service 在构造时自动注册到 `page._services`，不能挂进树。
6. **demo 的 `section(title, hint, *controls)` 被误用成 `section(title, *controls)`**：
   hint 字符串落进 `Column.controls` → Flutter 渲染成整块灰色 ErrorWidget。
   已加构造期类型校验（hint 必须 str，正文必须 Control/Component）。
7. **`not_found` 必须返回控件而非 `ft.View`**。
8. demo 里 `ft.Button`（flet 1.0.0 的 Button 没有 `style_type` 等参数）应为项目 `ui.Button`；
   `ListView(divider_color=...)` 已移除。

## 修复：outline_input 颜色效果无效

**根因**：`OutlineInputBorder.side` 的类型是**单个** `ft.BorderSide`，不是状态字典。
旧 `styles.outline_input()` 把 `{ControlState: BorderSide}` 塞进 `side`，Python 侧不校验、
客户端解析不出颜色后**静默退回 `BorderSide` 默认值（黑色）**，全无报错。

**修法**（`src/ui/core/styles.py` 重写）：
- `outline_input()` / `underline_input()` 改为返回 **`dict[ControlState, InputBorder]`**，
  直接赋给 `FormFieldControl.border`；调用点签名不变，无需改动。
- 状态只写文档支持的 4 个：`DEFAULT` / `FOCUSED` / `ERROR` / `DISABLED`。
- 新增 `error_color` 参数（默认 `Colors.ERROR`），错误态边框自动变红。
- `color=None` 时 `DEFAULT.side` 不写，交给主题解析。
- **丢掉 `HOVERED`**：实测对输入边框**完全无效**（渲染不报错、悬停前后**零像素差异**）。
  附坑：字典形式下某状态条目若不写 `side`，会**继承 `DEFAULT` 的 `side`**。

**验证**（`scripts/_outline_probe_app.py` + `_probe_demo.py` 新增 `--hover`）
| 状态 | 结果 |
|---|---|
| 常规 | 红边 ✓（修复前是黑边） |
| FOCUSED（真实点击） | 绿边 ✓ |
| DISABLED | 灰边 ✓ |
| ERROR | 红边 + 错误文案 ✓ |
| `ui.Input` 聚焦 | 蓝边 ✓（`GREY_300` / `BLUE` 生效） |
| `HOVERED` | 零像素差异，确认无效 |
| 回归 | FormPage / NavigationPage / UploadPage / DisplayPage 视觉检查 4/4；6 个消费模块 `_ui_audit` 全 OK |
